## 遇到的问题
1. **StatsServiceImpl.java:162 编译错误** — `Collectors.groupingBy(r->..., TreeMap::new)` 缺少下游收集器，需要使用三参数版本 `(classifier, mapFactory, downstreamCollector)`。修复：加上 `Collectors.toList()`。
2. **NavBar.vue CSS 缺失** — `.navbar-user` 和 `.user-tag` 类无 CSS 声明，虽然 flexbox 可正常布局，但缺少视觉样式。已添加。
3. **MySQL 密码不匹配** — application.yml 原 root 密码错误，已更新为用户实际密码。
4. **数据库表结构不匹配** — 存在旧版本表结构（旧字段：money, remark, create_time），与实体类不匹配。解决：DROP 旧表，用 init.sql 重建。
5. **init.sql 中文编码错误** — mysql 客户端默认编码不匹配，需指定 `--default-character-set=utf8mb4`。
6. **端口 8080 被占用** — 旧应用进程未终止，需 kill 后重启。
7. **curl 中文 JSON 编码错误** — shell 中中文字符被错误编码导致 JSON 解析失败，使用 printf + 临时文件解决。
