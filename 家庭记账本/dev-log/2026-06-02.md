## 阶段 9 补充：AI 配置持久化与设置页管理

### 问题背景
AI 助手的 API Key 之前仅通过环境变量 `DASHSCOPE_API_KEY` 或 application.yml 配置。
部署到云服务器时，如果新服务器没有该环境变量，AI 功能将不可用（虽然不会崩溃，但会提示"暂未配置"）。

## 阶段 10：多用户权限管控与个人账单统计

### 需求背景
（1）每个家庭成员只能记自己的账单，但是可以看到整个家庭的收支账单。
（2）统计栏目，可以分别查看个人（所有个人）和家庭总账单。
（3）注册成功后，选择创建家庭账单或者加入家庭账单时，在该页面显示个人ID。
（4）AI助手只能修改本用户的账单，用户ID是标识该账单的重要关键字。

### 解决方案
为 Record 添加 `user_id` 字段，所有增删改操作校验 userId，统计接口新增 userId 筛选参数。

### 新增文件（1 个）

| 文件 | 说明 |
|------|------|
| `db/migration_v4.sql` | 为 record 表添加 user_id 列 + 索引 |

### 修改文件（12 个）

| 文件 | 改动 |
|------|------|
| `entity/Record.java` | 新增 `userId` 字段 |
| `dto/RecordQueryDTO.java` | 新增 `userId` 查询参数 |
| `mapper/RecordMapper.java` | `selectRecordPage` 增加 `userId` 参数 |
| `mapper/RecordMapper.xml` | SELECT 增加 `r.user_id AS userId`，WHERE 增加 `userId` 过滤 |
| `service/impl/RecordServiceImpl.java` | `addRecord()` 自动注入 userId；`updateRecord()`/`deleteRecord()` 校验 userId 权限 |
| `service/StatsService.java` | 所有统计方法增加 `Long userId` 参数 |
| `service/impl/StatsServiceImpl.java` | `getRecordsInRange()` 增加 userId 过滤条件 |
| `controller/StatsController.java` | 所有统计端点增加 `@RequestParam(required=false) Long userId` |
| `service/impl/AiServiceImpl.java` | 统计调用适配新参数；System Prompt 增加用户ID说明 |
| `frontend/src/views/StatsView.vue` | 新增「查看范围」下拉框：家庭总账单 / 个人账单（按userId筛选） |
| `frontend/src/views/FamilySetupView.vue` | 页面顶部显示用户个人ID（金色标签） |
| `frontend/src/views/RecordList.vue` | 新增「记录人」列；非本人记录隐藏编辑/删除按钮 |

### 设计细节

**权限模型：**
- 记录的 `userId` 由后端从 `UserContext.getUserId()` 自动注入，前端不可伪造
- `updateRecord` / `deleteRecord` 校验 `record.userId == currentUserId`，不匹配则抛出 `IllegalStateException`
- 历史数据（`userId` 为 NULL）允许任意操作，兼容旧数据

**统计双模式：**
- 传 `userId` → 只统计该用户的记录（个人账单）
- 不传 `userId` → 统计全家庭记录（家庭总账单）
- 前端下拉框通过成员列表生成选项，成员无 userId 则禁用

**前端权限按钮：**
- `RecordList.vue` 根据 `currentUserId` 判断是否显示编辑/删除按钮
- 历史数据（userId 为 null）仍显示按钮
