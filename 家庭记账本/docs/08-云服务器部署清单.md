# 08 — 云服务器部署操作清单

> 按顺序执行，每步完成后再进行下一步。

---

## 1. 本机打包

```bash
# 前端构建
cd d:\家庭记账本\frontend
npm run build

# 复制前端产物到后端静态资源目录
xcopy /E /Y dist\* ..\src\main\resources\static\

# 打包 Spring Boot（跳过测试）
cd d:\家庭记账本
mvn clean package -DskipTests
```

产物：`target/family-account-1.0.0.jar`（约 40MB）

---

## 2. 服务器环境准备

```bash
# 安装 JDK 17（二选一）
# CentOS/RHEL:
yum install -y java-17-openjdk
# Ubuntu/Debian:
apt install -y openjdk-17-jdk
```

MySQL 8.0 需已安装并运行，创建数据库：

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS family_account DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_unicode_ci;"
```

---

## 3. 上传文件到服务器

```bash
# 创建应用目录
ssh root@你的服务器IP "mkdir -p /opt/family-account"

# 上传 JAR 包和数据库脚本
scp target/family-account-1.0.0.jar root@你的服务器IP:/opt/family-account/
scp db\init.sql root@你的服务器IP:/opt/family-account/
scp db\migration_v4.sql root@你的服务器IP:/opt/family-account/
```

---

## 4. 初始化数据库（服务器上执行）

```bash
ssh root@你的服务器IP

# 建表 + 初始数据
mysql -u root -p family_account < /opt/family-account/init.sql

# ⚠️ 关键：执行 user_id 迁移（否则多用户权限功能报错）
mysql -u root -p family_account < /opt/family-account/migration_v4.sql
```

---

## 5. 配置 MySQL 连接

如果服务器 MySQL 密码与本机不同，创建外部配置文件：

```bash
cat > /opt/family-account/application.yml << 'EOF'
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/family_account?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: 你的MySQL密码
    driver-class-name: com.mysql.cj.jdbc.Driver
EOF
```

> 文件放在 JAR 同级目录，Spring Boot 会自动加载，无需重新打包。

---

## 6. 配置防火墙

**云服务器安全组：** 去阿里云/腾讯云等控制台 → 安全组规则 → 入方向 → 放行 TCP 8080。

**服务器本机防火墙：**

```bash
# firewalld（CentOS 7+）
firewall-cmd --zone=public --add-port=8080/tcp --permanent
firewall-cmd --reload

# ufw（Ubuntu）
ufw allow 8080/tcp
```

---

## 7. 启动应用

```bash
cd /opt/family-account

# 先前台测试（Ctrl+C 停止，确认无报错）
java -jar family-account-1.0.0.jar

# 确认正常后后台运行
nohup java -jar family-account-1.0.0.jar > app.log 2>&1 &

# 查看日志
tail -f /opt/family-account/app.log
```

> 低配服务器（1C2G）建议加内存限制：`java -Xmx256m -jar family-account-1.0.0.jar`

## 9. 配置 AI 助手（可选但推荐）

三种方式，按优先级：

**方式 A（设置页配置，推荐 ✅）：**  
登录 → 设置 → 🤖 AI 配置 → 粘贴 DashScope API Key → 保存。  
后台自动创建 `ai-config.properties`，无需碰服务器。

**方式 B（手动创建外部配置文件）：**
```bash
echo "api-key=sk-你的DashScopeKey" > /opt/family-account/ai-config.properties
```
重启应用即生效。

**方式 C（环境变量）：**
```bash
DASHSCOPE_API_KEY=sk-你的Key java -jar family-account-1.0.0.jar
```

### 获取 API Key

1. 访问 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 开通「灵积模型服务」
3. 在 API Key 管理页面创建 Key（sk- 开头）
4. `qwen-turbo` 有免费额度，个人使用通常够用

### 配置优先级

```
外部文件 (ai-config.properties)  >  环境变量 (DASHSCOPE_API_KEY)  >  application.yml
```

## 10. 设为系统服务（开机自启）

```bash
cat > /etc/systemd/system/family-account.service << 'EOF'
[Unit]
Description=家庭记账本
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/family-account
ExecStart=/usr/bin/java -jar /opt/family-account/family-account-1.0.0.jar
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now family-account
systemctl status family-account
```

常用命令：

```bash
systemctl stop family-account     # 停止
systemctl start family-account    # 启动
systemctl restart family-account  # 重启
journalctl -u family-account -f   # 查看日志
```

## ⚠️ 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 启动报错 "Unknown column 'user_id'" | 未执行 migration_v4.sql | `mysql -u root -p family_account < migration_v4.sql` |
| 启动报错 "Access denied for user" | MySQL 密码不对 | 检查 application.yml 中的密码 |
| 浏览器无法访问 | 防火墙/安全组未放行 | 检查安全组规则和本机防火墙 |
| 前端页面空白 | 静态资源未打入 JAR | 重新执行 `npm run build` 和 `xcopy`，再 `mvn package` |
| 图表不显示 | ECharts 未安装 | `cd frontend && npm install` |
| JVM 内存不足 | 服务器配置低 | 加 `-Xmx256m` 参数 |
| AI 提示"暂未配置" | API Key 未设置 | 按第 9 步配置 API Key |

## 部署架构

```
用户浏览器
    │
    ▼
http://服务器IP:8080
    │
    ▼
Spring Boot (内嵌 Tomcat)
    ├── /               → 前端静态资源 (Vue 3 SPA)
    ├── /api/**         → REST API (业务逻辑)
    └── /doc.html       → Knife4j API 文档
    │
    ▼
MySQL 8.0 (family_account)
```

> **单 JAR 部署**：前端和后端合并为一个 JAR 包，只需 `java -jar` 一个命令，无需单独部署 Nginx 或 Node 服务。
