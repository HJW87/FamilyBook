# 03 — UI 设计规范

## 1. 配色方案

### 1.1 主题色（暖黄色系）

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--primary-bg` | `#FFF8DC` | 页面主背景（玉米色 Cornsilk） |
| `--primary-light` | `#FFFDF5` | 卡片/弹窗背景 |
| `--primary-dark` | `#F5DEB3` | 表头、面板标题背景（小麦色 Wheat） |
| `--accent` | `#FFA500` | 主按钮、激活状态、强调元素（橙色 Orange） |
| `--accent-hover` | `#E8960A` | 按钮悬停态 |
| `--accent-light` | `#FFF0D4` | 选中行高亮 |
| `--text-primary` | `#333333` | 主文字 |
| `--text-secondary` | `#666666` | 次要文字 |
| `--text-placeholder` | `#999999` | 占位符文字 |
| `--border` | `#E0D5B8` | 边框色 |
| `--border-light` | `#F0EBD8` | 浅边框 |
| `--income` | `#27AE60` | 收入金额/标签（绿色） |
| `--income-bg` | `#E8F8F0` | 收入背景 |
| `--expense` | `#E74C3C` | 支出金额/标签（红色） |
| `--expense-bg` | `#FDEDEC` | 支出背景 |
| `--danger` | `#E74C3C` | 删除按钮 |
| `--danger-hover` | `#C0392B` | 删除按钮悬停 |
| `--white` | `#FFFFFF` | 纯白 |
| `--shadow` | `0 2px 12px rgba(0,0,0,0.08)` | 卡片阴影 |
| `--radius` | `8px` | 统一圆角 |

### 1.2 Element Plus 主题覆盖

```css
:root {
  --el-color-primary: #FFA500;
  --el-color-primary-light-3: #FFB733;
  --el-color-primary-light-5: #FFC966;
  --el-color-primary-light-7: #FFDB99;
  --el-color-primary-light-9: #FFEDCC;
  --el-color-primary-dark-2: #E8960A;
  --el-bg-color-page: #FFF8DC;
  --el-border-radius-base: 8px;
}
```

## 2. 布局规范

### 2.1 整体布局
```
┌────────────────────────────────────────────┐
│  NavBar (高度 60px, 固定顶部)                │
│  🏠 家庭记账本    [记账] [明细] [统计] [设置]  │
├────────────────────────────────────────────┤
│                                            │
│  Main Content (max-width: 1200px, 居中)     │
│  padding: 24px                             │
│                                            │
├────────────────────────────────────────────┤
│  Footer (可选, 高度 40px)                    │
│  本月收入 ¥12,000  |  本月支出 ¥8,500         │
└────────────────────────────────────────────┘
```

### 2.2 间距规范
- 页面内边距：24px
- 卡片内边距：20px
- 组件间距：16px
- 表单项间距：16px
- 列表项间距：12px

### 2.3 字体规范
- 主字体：系统默认（`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`）
- 标题：18px / 700 weight
- 副标题：16px / 600 weight
- 正文：14px / 400 weight
- 辅助文字：12px / 400 weight
- 金额数字：16px~24px / 600 weight（等宽数字）

## 3. 组件规范

### 3.1 按钮
- 主按钮：橙色背景 + 白色文字，hover 加深
- 次按钮：橙色边框 + 橙色文字，hover 浅橙背景
- 危险按钮：红色背景（仅在删除/清空操作使用）
- 最小宽度：80px
- 圆角：8px

### 3.2 表单
- 标签宽度：80px（右对齐）
- 输入框高度：40px
- 聚焦边框色：`--accent`
- 错误状态：红色边框 + 红色提示文字

### 3.3 表格
- 表头背景：`--primary-dark`
- 行 hover：`--accent-light`
- 斑马纹：可选（`--primary-bg` 与 `--white` 交替）
- 操作列宽度：120px

### 3.4 弹窗
- 宽度：480px（表单弹窗）/ 320px（确认弹窗）
- 圆角：12px
- 遮罩层：rgba(0,0,0,0.45)
- 标题：16px / 600 weight
- 确认按钮：橙色，取消按钮：默认

### 3.5 卡片
- 背景：`--white`
- 阴影：`--shadow`
- 圆角：`--radius`
- 内边距：20px

### 4.2 图表通用配置
- 字体大小：12px
- 提示框：圆角 6px，阴影
- 饼图：显示标签 + 百分比
- 柱状图：圆角柱，宽度 60%
- 折线图：平滑曲线，圆点标记

## 5. 响应式断点

| 断点 | 宽度 | 适配策略 |
|------|------|----------|
| 桌面 | ≥1024px | 最大宽度 1200px 居中，两列布局 |
| 平板 | 768px~1023px | 单列布局，侧边栏收起 |
| 手机 | <768px | 全宽布局，表格横向滚动，导航改为底部固定 |

## 6. 交互规范

### 6.1 加载状态
- 列表/表格：v-loading 骨架或加载中图标
- 按钮：点击后显示 loading + 禁用
- 图表：加载中占位

### 6.2 空状态
- 使用 el-empty 组件
- 描述文字：如"暂无记录，去记一笔吧~"

### 6.3 错误提示
- 表单校验错误：输入框下方红色文字
- 操作失败：ElMessage.error 顶部通知
- 网络错误：统一拦截显示"网络异常，请稍后重试"

### 6.4 成功反馈
- 操作成功：ElMessage.success 顶部通知（2秒自动消失）
- 数据保存后：表单重置 / 列表刷新

### 6.5 危险操作
- 删除单条：el-popconfirm 气泡确认
- 清空数据：弹窗 + 输入"确认清空"文字二次确认
