## 2. 数据库准备

### 2.1 创建数据库
```sql
CREATE DATABASE family_account
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

### 2.2 配置连接
编辑 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/family_account?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root        # 改成你的 MySQL 用户名
    password: root        # 改成你的 MySQL 密码
    driver-class-name: com.mysql.cj.jdbc.Driver
```

> 表不需要手动创建，Spring Boot 启动时 JPA 会自动建表（`ddl-auto: update` 模式，由 MyBatis-Plus 配合）。

注意：实际使用的是 MyBatis-Plus，需要额外配置 `spring.sql.init.mode=always` 或让 DataInitializer 在启动时调用 init.sql。

## 6. 常见问题

### Q1：启动报错 "Access denied for user"
→ MySQL 用户名或密码不正确，检查 `application.yml` 配置。

### Q2：启动报错 "Unknown database 'family_account'"
→ 数据库未创建，先执行第 2 步的建库 SQL。

### Q3：启动报错 "Public Key Retrieval is not allowed"
→ 在 `application.yml` 的 datasource url 后面加上 `&allowPublicKeyRetrieval=true`。

### Q4：前端访问后端接口报 CORS 错误
→ 检查 `CorsConfig.java` 是否配置正确，或检查后端是否启动。

### Q5：前端页面空白
→ 检查浏览器控制台报错，确认后端已启动且端口正确。

### Q6：ECharts 图表不显示
→ 检查 ECharts 是否正确安装：`npm list echarts`
→ 检查图表容器是否有宽度和高度。

## 8. 🚀 服务器部署（重要！）

### 8.1 部署架构说明

部署后，前端和后端合并为一个 jar 包，只需要一个命令启动，访问同一个端口（8080）即可使用。

```
用户浏览器 → http://服务器IP:8080 → Spring Boot（静态资源 + API）
```

### 8.2 一键打包（推荐方式）

在项目根目录执行：

```bash
# 第一步：构建前端
cd frontend
npm install
npm run build

# 第二步：将前端产物复制到后端静态资源目录
# Windows:
xcopy /E /Y dist\* ..\src\main\resources\static\

# Linux/Mac:
cp -r dist/* ../src/main/resources/static/

# 第三步：打包 Spring Boot（含前端）
cd ..
mvn clean package -DskipTests
```

打包完成后，`target/family-account-1.0.0.jar` 就是可部署的完整应用。

### 8.3 使用 Maven Profile 一键打包（全自动）

```bash
# 自动构建前端 + 打包后端（需要本机有 Node.js）
mvn clean package -DskipTests -Pdeploy
```

### 8.4 上传到服务器

```bash
# 将 jar 包上传到服务器（替换为实际 IP）
scp target/family-account-1.0.0.jar root@你的服务器IP:/opt/family-account/

# 同时上传 application.yml 配置文件（如果服务器 MySQL 配置不同）
scp src/main/resources/application.yml root@你的服务器IP:/opt/family-account/
```

### 8.5 在服务器上运行

```bash
# SSH 登录服务器
ssh root@你的服务器IP

# 进入应用目录
cd /opt/family-account

# 确保 MySQL 已安装并创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS family_account DEFAULT CHARACTER SET utf8mb4;"

# 启动应用（前台）
java -jar family-account-1.0.0.jar

# 后台启动（推荐）
nohup java -jar family-account-1.0.0.jar > app.log 2>&1 &

# 查看日志
tail -f app.log

# 停止应用
ps -ef | grep family-account
kill -9 <PID>
```

启动后访问：`http://你的服务器IP:8080`

### 8.6 使用外部配置文件（服务器 MySQL 密码不同时）

```bash
# 将 application.yml 放在 jar 包同级目录，Spring Boot 会自动加载
java -jar family-account-1.0.0.jar --spring.config.location=file:./application.yml
```

### 8.9 使用 systemd 设为开机自启（可选）

```bash
# 创建服务文件
cat > /etc/systemd/system/family-account.service << EOF
[Unit]
Description=家庭记账本
After=network.target mysql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/family-account
Environment="DASHSCOPE_API_KEY=sk-你的DashScopeKey"
ExecStart=/usr/bin/java -jar /opt/family-account/family-account-1.0.0.jar
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 启动并设为开机自启
systemctl daemon-reload
systemctl start family-account
systemctl enable family-account
systemctl status family-account
```

### 8.10 配置 AI 助手（通义千问）

AI 记账助手需要 DashScope API Key。支持三种配置方式，按优先级从高到低：

#### 方式一：设置页配置（推荐 ✅）

部署后访问 `http://服务器IP:8080` → 登录 → 设置 → **🤖 AI 配置**，直接粘贴 API Key 并保存。

保存后 JAR 同级目录会自动生成 `ai-config.properties` 文件，重启后自动加载，**无需任何服务器操作**。

#### 方式二：创建外部配置文件

在 JAR 同级目录手动创建 `ai-config.properties`：

```bash
echo "api-key=sk-你的DashScopeKey" > /opt/family-account/ai-config.properties
```

重启应用即生效，优先级高于环境变量。

#### 方式三：环境变量（systemd）

编辑 systemd 服务文件，添加 Environment 行：

```ini
# /etc/systemd/system/family-account.service
[Service]
Environment="DASHSCOPE_API_KEY=sk-你的DashScopeKey"
```

然后 `systemctl daemon-reload && systemctl restart family-account`。

#### 获取 API Key

1. 访问 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 开通「灵积模型服务」
3. 在 API Key 管理页面创建 Key（sk-开头）
4. `qwen-turbo` 有免费额度，个人使用通常够用

#### 配置优先级

```
外部文件 (ai-config.properties) > 环境变量 (DASHSCOPE_API_KEY) > application.yml
```

> **注意**：如果通过设置页保存了 API Key，会自动创建外部配置文件，后续都以该文件为准。如需切换 Key 来源，在设置页点击"清除外部配置"即可回退到环境变量。
