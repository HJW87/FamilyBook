# 01 — 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
家庭记账本（Family Account Book）

### 1.2 项目背景
家庭日常财务收支管理缺乏系统化工具，需要一款轻量级 Web 应用来记录、查询、统计家庭的收入和支出情况。

### 1.3 目标用户
- 家庭成员（通过"家庭成员"字段区分每笔账的归属）
- 单机使用，无需多用户登录

### 1.4 运行环境
- 后端：Java 17+，Spring Boot 3.x
- 数据库：MySQL 8.0
- 前端：现代浏览器（Chrome / Edge / Firefox）
- 开发工具：IntelliJ IDEA

---

## 2. 功能需求

### 2.1 收支分类管理（F-01）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-01-01 | 预设类别 | 系统预置 6 个收入类别 + 10 个支出类别 |
| F-01-02 | 查看类别 | 按收入/支出类型切换查看类别列表 |
| F-01-03 | 添加类别 | 自定义添加新类别（名称 + emoji 图标 + 收支类型） |
| F-01-04 | 修改类别 | 修改已有类别的名称、图标、排序 |
| F-01-05 | 删除类别 | 删除自定义类别（已被记录引用的类别禁止删除） |

### 2.2 收支记录管理（F-02）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-02-01 | 添加记录 | 录入一笔收支（类型、金额、类别、日期、成员、备注） |
| F-02-02 | 查看记录 | 分页列表展示所有记录，按日期分组 |
| F-02-03 | 修改记录 | 编辑已有记录的任意字段 |
| F-02-04 | 删除记录 | 删除单条记录（需确认） |

### 2.3 收支查询（F-03）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-03-01 | 按类型筛选 | 筛选全部 / 仅收入 / 仅支出 |
| F-03-02 | 按类别筛选 | 下拉选择具体类别 |
| F-03-03 | 按成员筛选 | 下拉选择家庭成员 |
| F-03-04 | 按日期范围筛选 | 选择起止日期 |
| F-03-05 | 关键词搜索 | 搜索备注内容 |
| F-03-06 | 组合筛选 | 以上条件可任意组合，实时刷新结果 |
| F-03-07 | 重置筛选 | 一键清空所有筛选条件 |

### 2.4 汇总统计（F-04）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-04-01 | 时间维度选择 | 本年 / 本月 / 本周 / 今日 / 自定义范围 |
| F-04-02 | 收支汇总 | 总收入金额、总支出金额、结余金额 |
| F-04-03 | 分类统计 | 按类别分组统计金额和占比（饼图 + 表格） |
| F-04-04 | 成员统计 | 按家庭成员分组统计（柱状图） |
| F-04-05 | 月度趋势 | 近 12 个月收支趋势（折线图） |

### 2.5 家庭成员管理（F-05）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-05-01 | 查看成员 | 列表展示所有家庭成员 |
| F-05-02 | 添加成员 | 输入成员名称添加 |
| F-05-03 | 删除成员 | 删除成员（已被记录引用的成员禁止删除） |

### 2.6 数据管理（F-06）
| 编号 | 功能 | 描述 |
|------|------|------|
| F-06-01 | 导出数据 | 将全部数据导出为 JSON 文件下载 |
| F-06-02 | 导入数据 | 上传 JSON 文件合并导入数据 |
| F-06-03 | 清空数据 | 清空所有数据（需二次确认） |

## 3. 非功能需求

### 3.1 性能要求
- 页面加载时间 < 2 秒
- 列表数据渲染 < 500ms（单页 20 条）
- 图表渲染 < 1 秒

### 3.2 可用性要求
- UI 简洁直观，无需培训即可使用
- 表单校验提示清晰友好
- 错误操作有明确反馈

### 3.3 数据安全
- 删除操作需确认
- 数据清空需二次确认
- 支持数据导出备份

### 3.4 兼容性
- 桌面端：Chrome / Edge / Firefox 最新版
- 移动端：响应式适配（≥375px 宽度）

---

## 4. 用户故事

1. **记账**：作为家庭成员，我希望能快速记录一笔收支，选择类型、金额、类别和日期即可完成。
2. **查账**：作为家庭成员，我希望能按时间、类别、成员等条件筛选查看历史记录。
3. **统计**：作为家庭管理者，我希望能看到本月花了多少钱、花在哪里、谁花的最多。
4. **管理**：作为使用者，我希望能自定义收支类别、管理家庭成员、备份数据。
