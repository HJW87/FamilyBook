## 2. ER 关系

```
┌──────────┐     ┌───────────────┐     ┌──────────┐
│  users   │     │ family_member │     │  family  │
│ (登录账号) │────>│  (身份标签)    │<────│  (家庭)   │
│          │ 1:1 │               │ N:1 │          │
│ username │     │ name="爸爸"    │     │ name     │
│ password │     │ user_id ──────┤     │ admin_id │
│display_id│     │ family_id     │     │invite_code│
└──────────┘     └───────────────┘     └──────────┘
       │                │                    │
       │         ┌──────┴──────┐             │
       │         │   record    │ (family_id) │
       │         │  category   │ (family_id) │
       │         └─────────────┘             │
       └─────────────────────────────────────┘
             所有数据通过 family_id 隔离

核心概念：
- users：登录账号（username + password + displayId）
- family：家庭记账本（name + invite_code + admin_id）
- family_member：家庭内的身份标签/座位（name + 可选绑定的 user_id）
  - 一个家庭有多个标签（N:1 → family）
  - 一个标签最多绑定一个用户（0..1:1 → user）
  - 一个用户只能属于一个家庭（通过标签绑定）
```

## 3. 表结构

### 3.1 users — 用户表

| 列名 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 用户ID |
| `username` | VARCHAR(50) | NOT NULL, UNIQUE | — | 用户名（登录用） |
| `password` | VARCHAR(255) | NOT NULL | — | BCrypt 加密密码 |
| `display_id` | BIGINT | UNIQUE | — | 用户展示ID（100001 格式） |
| `created_at` | TIMESTAMP | — | CURRENT_TIMESTAMP | 注册时间 |

**索引：** PK `id`，UNIQUE `username`，UNIQUE `display_id`

### 3.2 family — 家庭表

| 列名 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 家庭ID |
| `name` | VARCHAR(100) | NOT NULL | — | 家庭名称 |
| `invite_code` | VARCHAR(20) | NOT NULL, UNIQUE | — | 8位邀请码 |
| `admin_id` | BIGINT | NOT NULL, FK | — | 管理员用户ID |
| `created_at` | TIMESTAMP | — | CURRENT_TIMESTAMP | 创建时间 |

**索引：** PK `id`，UNIQUE `invite_code`，FK `admin_id` → `users(id)`

### 3.3 family_member — 家庭成员（身份标签）表

| 列名 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 成员标签ID |
| `name` | VARCHAR(50) | NOT NULL | — | 身份标签名称（如"爸爸"） |
| `family_id` | BIGINT | NOT NULL, FK | — | 所属家庭ID |
| `user_id` | BIGINT | UNIQUE, FK | NULL | 绑定的用户ID（NULL=空座位） |
| `created_at` | TIMESTAMP | — | CURRENT_TIMESTAMP | 创建时间 |

**索引：** PK `id`，UNIQUE `user_id`，INDEX `idx_family_id` (`family_id`)，FK `family_id` → `family(id)`，FK `user_id` → `users(id)`

> **设计说明：** 同一家庭内标签名不能重复（业务层校验）。user_id 设 UNIQUE 保证一个用户只能占一个标签位。

### 3.4 category — 收支类别表

| 列名 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 类别ID |
| `name` | VARCHAR(50) | NOT NULL | — | 类别名称 |
| `type` | VARCHAR(10) | NOT NULL | — | 类型：INCOME / EXPENSE |
| `icon` | VARCHAR(10) | — | '📦' | emoji 图标 |
| `sort_order` | INT | — | 0 | 排序权重（越大越靠前） |
| `family_id` | BIGINT | NOT NULL, FK | — | 所属家庭ID |
| `created_at` | TIMESTAMP | — | CURRENT_TIMESTAMP | 创建时间 |

**索引：** PK `id`，INDEX `idx_family_type` (`family_id`, `type`)，FK `family_id` → `family(id)`

### 3.5 record — 收支记录表

| 列名 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 记录ID |
| `type` | VARCHAR(10) | NOT NULL | — | 类型：INCOME / EXPENSE |
| `category_id` | BIGINT | NOT NULL, FK | — | 关联类别ID |
| `amount` | DECIMAL(10,2) | NOT NULL | — | 金额 |
| `family_member` | VARCHAR(50) | NOT NULL | — | 家庭成员名称 |
| `record_date` | DATE | NOT NULL | — | 记账日期 |
| `note` | VARCHAR(200) | — | '' | 备注 |
| `family_id` | BIGINT | NOT NULL, FK | — | 所属家庭ID |
| `created_at` | TIMESTAMP | — | CURRENT_TIMESTAMP | 创建时间 |

**索引：** PK `id`，INDEX `idx_record_date` (`record_date`)，INDEX `idx_type` (`type`)，INDEX `idx_category_id` (`category_id`)，INDEX `idx_family_member` (`family_member`)，INDEX `idx_family_id` (`family_id`)，FK `category_id` → `category(id)`，FK `family_id` → `family(id)`

## 6. 关键 SQL 查询

### 6.1 按类别统计支出（统计接口用）
```sql
SELECT c.id, c.name, c.icon, COUNT(r.id) AS count, SUM(r.amount) AS total
FROM record r
JOIN category c ON r.category_id = c.id
WHERE r.type = 'EXPENSE'
  AND r.family_id = #{familyId}
  AND r.record_date BETWEEN #{startDate} AND #{endDate}
GROUP BY c.id, c.name, c.icon
ORDER BY total DESC;
```

### 6.2 月度趋势（统计接口用）
```sql
SELECT
  DATE_FORMAT(record_date, '%Y-%m') AS month,
  type,
  SUM(amount) AS total
FROM record
WHERE family_id = #{familyId}
  AND record_date >= DATE_SUB(CURDATE(), INTERVAL 12 MONTH)
GROUP BY DATE_FORMAT(record_date, '%Y-%m'), type
ORDER BY month;
```

### 6.3 多条件筛选查询（记录列表用）
```sql
SELECT r.*, c.name AS category_name, c.icon AS category_icon
FROM record r
LEFT JOIN category c ON r.category_id = c.id
WHERE r.family_id = #{familyId}
<where>
  <if test="type != null">AND r.type = #{type}</if>
  <if test="categoryId != null">AND r.category_id = #{categoryId}</if>
  <if test="familyMember != null">AND r.family_member = #{familyMember}</if>
  <if test="startDate != null">AND r.record_date >= #{startDate}</if>
  <if test="endDate != null">AND r.record_date <= #{endDate}</if>
  <if test="keyword != null">AND r.note LIKE CONCAT('%', #{keyword}, '%')</if>
</where>
ORDER BY r.record_date DESC, r.created_at DESC;
```

### 6.4 登录验证
```sql
SELECT * FROM users WHERE username = #{username};
-- 然后用 BCryptPasswordEncoder.matches(rawPassword, encodedPassword) 验证
```

### 6.5 通过展示ID查找用户
```sql
SELECT * FROM users WHERE display_id = #{displayId};
```
