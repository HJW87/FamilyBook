## 2. 版本锁定

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
```

## 3. 架构模式

### 3.1 后端分层架构
```
Controller → Service(接口) → ServiceImpl → Mapper → Database
    ↑            ↑              ↑            ↑
  REST API    业务逻辑     事务管理     数据访问
```

### 3.2 前端组件架构
```
App.vue
  └── AppLayout.vue
        ├── NavBar.vue
        └── <router-view>
              ├── RecordAdd.vue
              ├── RecordList.vue
              ├── StatsView.vue
              │     └── SummaryCards.vue
              └── SettingsView.vue
```

### 3.3 数据流
```
[Vue 组件] → Axios → [Spring Controller] → Service → Mapper → MySQL
                                                              ↓
[Vue 组件] ← JSON ← [Spring Controller] ← Service ← Mapper ← MySQL
```

## 4. 项目命名规范

### 4.1 Java 命名
- 包名：全小写 `com.familyaccount`
- 类名：PascalCase `RecordController`, `CategoryService`
- 方法名：camelCase `getRecordList`, `addCategory`
- 常量：UPPER_SNAKE_CASE
- 数据库列：snake_case

### 4.2 前端命名
- 组件文件：PascalCase `RecordList.vue`
- JS 文件：camelCase `request.js`
- CSS 类：kebab-case `.summary-cards`
- 路由路径：kebab-case `/record-list`

### 4.3 REST API 命名
- 基础路径：`/api/`
- 资源名：复数形式 `/api/records`, `/api/categories`
- 统计：`/api/stats/` 前缀
